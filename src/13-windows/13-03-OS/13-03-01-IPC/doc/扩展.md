如果你想让它更像 Weasel，可以逐步加：

1. 改成二进制协议：定义 struct KeyEvent { UINT keycode; UINT mask; };
客户端发送结构体，服务端解析。
2. 模拟输入法逻辑：服务端维护一个简单映射表，比如：
输入 nihao → 返回候选 ["你好", "你号", "泥壕"]
3. 客户端显示候选列表，按数字选词。
4. 改成 DLL 注入：把客户端做成 DLL，用 SetWindowsHookEx 挂键盘钩子，注入到记事本里，捕获真实按键。
5. 加多客户端支持：服务端用多线程，每个客户端一个管道实例，模拟多个应用同时用输入法。
6.加超时和断线重连：客户端检测服务端是否存活，断了就重连。
